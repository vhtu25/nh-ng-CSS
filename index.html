Bài tập Nhúng CSS vào trang HTML

Phần 1: Inline Style

Đoạn văn này được đổi màu bằng Inline Style (màu đỏ).

Phần 2: Internal Style

Đoạn văn này được đổi màu bằng Internal Style (màu xanh dương).

Phần 3: External Style

Đoạn văn này được đổi màu bằng External Style thông qua file style.css (màu xanh lá).
